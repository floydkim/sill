# 원격 연결 중 화면 가리기 구현 계획

**목표:** 호스트의 저장 가능한 설정으로 물리 화면을 가리고, 마지막 유효 원격 세션 종료 시 잠금을 확인한 뒤 덮개를 제거한다.
**설계:** 기존 실험 창과 Desktop의 Sill 앱 제외 필터를 활용한다. 설정은 HostConfig → HostSettings → GeneralPane으로 연결하며 프로토콜에는 노출하지 않는다. 기본값은 꺼짐이다. 실험의 180초 제한은 제거한다. 기존 SessionLock에 명시적인 잠금 확인과 런타임 잠금 요청을 추가한다. 잠금 요청은 비공개 login.framework 함수를 동적으로 확인해 사용하고, 없거나 확인 실패 시 덮개를 유지한다. 연결/설정 변화 중 오래된 비동기 결과로 덮개가 사라지지 않도록 현재 상태를 다시 확인한다.

1. PrivacyCurtain으로 실험을 정리하고, 설정과 유효 세션 생명주기에 연결한다. 로컬 해제 단축키는 현재 연결 동안만 가리기를 중지하며 재접속 때 다시 적용한다.
2. 마지막 유효 세션 이탈·권한 회수·설정 해제에서 잠금 확인 후 제거한다. 앱 정상 종료와 SIGTERM도 잠금 확인을 선행한다. 강제 종료·충돌은 보호 보장 범위 밖이다.
3. HostConfig/HostSettings에 hideLocalScreen을 추가하고 GeneralPane에 설정·설명·오류를 보여준다. 모바일/뷰어 프로토콜에는 변경을 추가하지 않는다.
4. 기존 빌드와 관련 확인 스크립트를 실행한다. 사용자 요청대로 새 영구 테스트 코드는 만들지 않는다. 테스트 호스트를 갱신하고 모바일 연결·잠금 해제·종료 후 잠금을 실제 확인한다.
5. 한국어 Conventional Commit으로 커밋한다. 사용자가 자율 커밋을 승인했다. 이번 턴에 별도 푸시 요청은 없으므로 자동 푸시는 하지 않는다.

화면 꺼짐에서 접속할 때의 캡처 복구 및 Mac 뷰어 잠금 표시는 다음 변경으로 분리한다. 다중 모니터와 프레임 단위 전환 무노출은 별도 검증 대상이다.

## 완료 확인

호스트/CLI 빌드와 기존 away-quality 검사 통과. 모바일에서 영상·버튼·종료 후 자동 잠금 확인. 잠금 상태 즉시 덮개를 제거하던 버전의 작업 창 fade-out 흔적을 보완해, 잠금 확인 후 1초 대기와 재확인을 모든 자동 제거 경로에 적용했다. 재시험에서 사용자는 검은 덮개 자체의 fade-out만 보여 목적에 부합한다고 확인했다. 리뷰의 취소된 잠금 Task 재접속 경계 문제도 수정했다.
