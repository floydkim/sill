# Mac 호스트·뷰어 UI 한국어 번역 계획

목표: 개인용 포크의 Mac 앱 두 개에서 사용자에게 보이는 메뉴, 설정, 연결 상태, 권한 안내, 오류, 접근성 설명을 한국어로 제공한다. 기존 구조의 문자열을 직접 번역하며 언어 선택기나 새 의존성을 추가하지 않는다.

1. 뷰어 화면·연결 흐름, 호스트 설정·페어링 화면, 호스트 상태·업데이트 문구를 파일 소유권을 나눠 병렬 번역한다. 공유 상태 모델에서 UI로 전달되는 문구와 앱의 권한 사용 설명은 통합 단계에서 확인한다.
2. 용어는 화면 기록, 손쉬운 사용, 가상 디스플레이, 연결 해제, 데스크탑, 페어링으로 통일한다. Sill 등 제품 이름은 유지한다. 품질 이름은 각 UI 타깃의 작은 표시용 확장으로 번역한다.
3. 번들 ID, 실행 파일, 앱 경로, 설정 키, raw enum 값, JSON 및 통신 규격은 유지한다. 시스템에서 전달한 상세 오류와 원격 앱 제목은 원문을 유지할 수 있다. 로그 전용 문구와 CLI는 번역 대상이 아니다.
4. 기존 검사 중 영어 UI 문구를 정확히 비교하는 경우 새 문구에 맞게 기대값만 갱신한다. 새 테스트 코드는 추가하지 않는다. 호스트·뷰어 빌드와 패키징·서명을 확인하고 실제 화면에서 잘림과 미번역을 살핀다.
5. 현재 앱의 연결 여부를 확인한 뒤 사용 중인 테스트 호스트와 설치된 뷰어를 갱신한다. 원본 정식 호스트 설치는 교체하지 않는다. 한국어 Conventional Commit으로 커밋하고 푸시는 별도 요청 시 진행한다.

## 완료 확인

호스트·뷰어 릴리즈 빌드와 앱 패키징·서명 통과. 기존 업데이트 검사 124개, 페어링 주소 검사 80개(무작위 5,000회 포함), 방화벽 검사 390개가 모두 통과했다. 영어 UI 기대값만 한국어로 갱신했으며 새 테스트는 추가하지 않았다. 코드 리뷰에서 설정 키·통신 식별자·단축키 변경은 발견되지 않았다. 실제 뷰어 연결 화면과 호스트 일반·기기·스트리밍·가상 디스플레이·권한·원격 접속 탭의 한국어 표시 및 주요 줄바꿈을 확인했다. 기존 화면 기록·손쉬운 사용 권한과 설정도 유지됐다.

뷰어는 기존 설치 경로, 호스트는 권한을 허용한 별도 테스트 앱 경로에 갱신했다. 원격 연결 중 화면·실패 분기 전체의 실제 기기 검증은 이번 번역 작업에서 반복하지 않았다. 원본 시스템 오류, 원격 창 제목과 기기 이름, 모바일 앱에 실제 표시되는 영문 버튼 이름은 원문으로 남길 수 있다.
