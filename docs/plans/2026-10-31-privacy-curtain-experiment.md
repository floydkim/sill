# 검은 덮개 전환 실험 계획

목표: 원격 연결 중 미리 표시한 검은 창이 잠금 화면 아래에서 유지되고, 잠금 해제 직후 물리 모니터를 가리면서 원격 영상과 입력은 정상인지 확인한다.

승인된 범위: 사용자가 잠금 해제 즉시 덮는 방식의 실제 테스트를 요청했다. 기존 체크아웃에서 실험 플래그로만 활성화하며, 정식 설정 UI와 프로토콜 변경은 이번 실험에서 제외한다. 커밋은 별도 승인 전에는 하지 않는다.

1. SillHost의 별도 실험 컴포넌트에서 물리 화면별 검은 창을 만든다. 기존 Sill 가상 디스플레이에는 만들지 않는다. 창은 포커스와 클릭을 가로채지 않고 모든 Space에 표시한다.
2. StreamCoordinator의 유효 세션 접속에서 활성화, 마지막 연결 종료와 앱 종료에서 제거한다. SILL_TEST_PRIVACY_CURTAIN=1일 때만 동작한다. 안전을 위해 180초 뒤 자동 해제하고 해당 프로세스에서 다시 활성화하지 않는다.
3. 잠금 해제와 화면 구성 변경 시 창 배치를 다시 확인한다. 잠금 시 창을 없애지 않아 알림 후 생성 지연을 줄인다. 잠금 화면 위에 덮개가 나타나지 않는지는 실제로 확인한다.
4. 기존 Desktop 캡처의 Sill 앱 제외 필터를 유지한다. 앱 창 캡처와 Desktop에서 원격 영상에 검은 창이 나타나는지 각각 확인한다.
5. 빌드·서명을 확인하고 별도 Sill Sleep Test.app을 갱신한다. 사용자 준비 확인 후 플래그를 켜고, 한국어 음성 안내에 따라 잠금·원격 잠금 해제·앱 클릭·연결 종료를 확인한다. 비밀번호는 사용자가 직접 입력하며 키 입력이나 비밀번호 화면을 수집하지 않는다.
6. 기존의 테스트 생략 요청에 따라 새 영구 테스트 코드는 작성하지 않는다. 빌드와 실제 기기 검증 결과를 기록한다. 전환의 단일 프레임 노출 방지는 육안 테스트만으로 보증하지 않는다.
